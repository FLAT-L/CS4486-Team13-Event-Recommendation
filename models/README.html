Experiment lineage

Environment

Target platform: macOS Apple Silicon. Select environment/.venv/bin/python as the notebook interpreter. All model code is in notebooks; shared functions live in environment/shared.ipynb. The package includes Python 3.12.14, local wheels and OpenMP. Moving to another OS requires platform-specific wheels.

After moving the package, open a terminal in models and run:

environment/python/bin/python3.12 -m venv --copies environment/.venv
environment/.venv/bin/python -m pip install --no-index --find-links environment/wheels -r environment/requirements.txt
environment/.venv/bin/python -m ipykernel install --prefix environment/.venv --name cs4486-models --display-name "CS4486 Models"

Execution

For 02, 05, 09 and 15, sections 1–3 load saved models and reproduce OOF scores. Section 4 rebuilds features from six raw tables. Section 5 retrains five folds with the recorded configuration. Parameters remain identical across folds.

For 01, sections 1–3 retrain RF and logistic regression from packaged historical features. Section 4 rebuilds full-table clustering, geographic inference and historical features. Its preprocessing is documented in two supporting notebooks. To train on newly rebuilt features, change the section 3 input path from reference/five_fold_features_utc.pkl to results/five_fold_features_utc.pkl.

Neural checkpoints and retraining

For 03, 04 and 06, execute sections 1–3 to reproduce five-fold MAP@200. Use a fresh kernel with the bundled macOS arm64 Python, PyTorch 2.14.0 and rtdl_revisiting_models 0.0.2. The notebooks select MPS when available and otherwise use CPU. In 03 and 06, section 2 compares regenerated neural coordinates with the original training inputs. Section 3 uses those original coordinates for tree inference. Each notebook records its check in results/verification.json.

Sections 4 onward train from the raw tables with fixed preprocessing and hyperparameters. 03 trains its event encoder and weighted trees. 04 trains five FT-Transformers. 06 reuses the packaged 03 checkpoint and retrains the dense compressor and trees. Full 06 training uses a temporary 15 GiB residual array. The ZIP contains the interpreter and offline wheels. All three neural verification sections passed after extracting the ZIP into a new directory and installing from those wheels. Use the three installation commands above after extracting it.

Regenerating the neural coordinates on CPU gave 0.717494 for 03 and 0.716736 for 06 with the same saved trees. Maximum coordinate differences from the original MPS inputs were 5.96 × 10−7 and 3.94 × 10−6. Tree thresholds can turn small numerical differences into ranking changes. Reloading the original coordinates and retraining the downstream trees reproduced 0.717325 and 0.717045. Model 04 reproduced 0.692191 directly from its five checkpoints on CPU.

Files

reference holds original features, saved models and scores. results receives new runs. data/raw contains the six required input tables. data/folds.csv records the original fold assignment. verification.json contains the numerical reproduction checks.

Evaluation

Users are assigned to five fixed folds. Each validation user is excluded from its fold’s supervised fit. MAP@200 averages per-user average precision. Experiments 05, 09 and 15 use the same fixed parameter set and seeds 42/2026 in all folds. Experiment 01 preserves its original deduplication, model blend and ranking rules.

Verified reproduction

The original five scores match the original records. Experiment 01 was retrained from packaged historical features. Experiments 02, 05, 09 and 15 rebuilt features from raw tables and retrained all five folds. A fresh offline installation and actual Jupyter kernel execution also passed.

Relocation check passed (November 7, 2026). A copied package ran the original five notebooks’ verification sections using its own Python environment and native libraries. All scores matched, with no reads from the original project directory. Verification record.
